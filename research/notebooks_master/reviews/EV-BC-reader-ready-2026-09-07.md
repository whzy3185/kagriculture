User direction: useful finished Notebooks with moderate quality, not academic
reports or low-value volume. Updated the plan's default editorial standard.

## What Changed

  Kaggle results. Live cells still recompute their own results.
- Shorter introduction, more readable result tables and specific practical takeaways.
- Keep full executable code and add direct reuse examples for splitting and fitted pipelines.
- Mark helper/diagnostic code with standard hidden-input metadata; local HTML
  reader previews hide those inputs while the .ipynb retains them for copying.
- Keep two meaningful plots per Notebook; no decorative or redundant charts.
- Replace large displayed manifest/JSON dumps with short summaries; full provenance
  remains in the output summary files and repository review records.
- Put the necessary environment-sensitivity explanation in a details section;
  preserve source attribution and uncertainty without repeating them throughout.
- Models, hyperparameters, sampling, validation splits and bootstrap logic unchanged.
