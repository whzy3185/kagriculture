# EXP-006: Independent Crop Controller

Latest user authorization permits improving an open-source foundation or building
an integrated agent from scratch and attempting a qualified Kaggle submission.
This experiment chooses independent implementation. No public-agent source,
weights or tapes enter the candidate. The existing root main.py is the legacy parent.

Hypothesis: a feasible crop controller with explicit working-capital budgets,
demand/supply pricing, reserved work, staffing and terminal transport improves
paired points over the legacy agent. The integrated architecture is the treatment;
feature-specific gains require separate ablations, not post-hoc attribution.

Pilot: seeds 101-104, both seats, versus legacy/starter/Shape v11. The latter is
an attributed Apache-2.0 public executable reference, outside the repository and
never included in our artifact. Source-only AST safety scan passed; runs have no
credentials and are network-disabled. No whole third-party Notebook is executed.

Development: seeds 201-216, both seats, the same three opponents. Holdout:
3001-3032, both seats; inspect once after freezing the chosen candidate. A separate
direct candidate-versus-parent comparison is included by the legacy opponent.
These are feasibility/promotion samples, not a claim of power for a two-point gain.

Four leave-one-module-out ablations: demand model, land, staffing, terminal
transport. Their purpose is to identify interaction/negative evidence. No separate
component claim unless its fixed-control contrast supports it.

Measure points, paired cash margins, per-opponent results, exact terminal states,
JSON/shape faults, non-PASS unit no-ops, market request/fill discrepancies and latency.
No error cases may be dropped. Failing controller versions receive new IDs/hashes.

Submission requires all actual gates, source/package hashes, a known Git commit,
nonduplicated artifact, no pending conflict, live quota, documented compliance,
and an actual Kaggle runtime check. First submission has parent_submission=null,
explicitly identifying legacy parent by code SHA instead of inventing an online score.
Do not alter root main.py until separately approved; submit a staged root-main artifact.
